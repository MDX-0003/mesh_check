# 共位检出把拆件界面误报成 z-fighting 缺陷——面积重叠率（overlap_frac）分型标准

- **日期**：2026-09-22
- **现象**：PLAN-04 v2 报告把 T2 批 19/20 个模型标为"共位双层面（z-fighting 风险）"共 277 条（`data/findings.jsonl`）；用户复核质疑：T2 原生多组件，组件间**贴合**是拆件的正常形态，不是共面缺陷——按现状交付会形成"T2 生成质量系统性崩坏"的误报叙事。对照 standard 批仅 9 条（观感"少数模型有问题"），反差印证了质疑。
- **根因**：两种几何现象在"bpy(1e-4 邻近焊接) 下组件消失"这一证据上**同因不同质**——①重复/退化曲面（真 z-fighting）：组件表面与另一组件表面几乎重合，焊接并走；②拆件界面（非缺陷）：T2 拆件时相邻部件**共享重合的界面顶点网格**（面与面对接、面积不重叠，界面在物体内部，渲染无伪影），焊接同样把共顶点的两部分熔成一体。A0 门（PLAN-03 §1.7）当年作为"防误删的保守门"两种一起拦是对的；v2 把它转正为检出器并贴上"共位双层面（z-fighting 风险）"标签后，两种形态被混成一种叙事。

## 判定标准（overlap_frac，讲解版）

**比值**：分子分母都是被检出组件自己的量——

```
              组件表面上"与最近邻组件表面重合"的那部分面积
overlap_frac = ──────────────────────────────────────────
                     组件自己的总表面积
```

不是体积比、不是邻居的面积、也不是距离值。**距离只负责入围（第 1 步证据门：单引擎可见 / 包围盒贴片），面积占比才负责定性。**

**三步测量**（立方体坐在平板上走一遍）：

1. **铺点**：在组件表面按面积加权铺 1500 个确定性采样点（`detectors.surface_samples`，R2 序列重心坐标，无 RNG）——每个点代表等面积的一小片表面（总面积/1500），所以**数点 = 量面积**。
2. **逐点量距离**：每点到最近邻组件表面（parts.jsonl 的 `nearest_rank`）的精确距离——`_SurfIndex` 质心 KD 树取 24 近邻候选三角形 + 解析点-三角形距离（`_pt_tri_dist`）。
3. **数容差内的点**：容差 = 模型对角线 × 1e-3（≈渲染深度精度量级，间距小于它渲染必然闪面）。重合点数 / 1500 = overlap_frac。

立方体例：6 个面只有底面贴平板 → 底面 250/1500 个点在容差内 → overlap_frac = 1/6 ≈ 0.167。真实对照：p19 rank0（3889 面大部件）仅 0.2% 的点在容差内 → 界面贴合；p01 的 2 面片 ~100% 在容差内 → 重复曲面。

**阈值与含义**（拟入 config `[parts]`，**尚未落地**）：

| 变量名（拟） | 值 | 含义 |
|---|---|---|
| `coloc_partial` | 0.2 | 下界：最"重"的合法界面（立方体叠立方体）重合面积也只有自身 1/6 ≈ 0.167；超过它，"部件对接"解释不了 |
| `coloc_true` | 0.6 | 上界：连极端扁平板件整面贴合也只有自身约一半（0.5）；超过它只剩"重复曲面"一种解释 |
| `coloc_overlap_tol` | 1e-3 | 重合判定容差（渲染深度精度） |
| `coloc_surface_samples` | 1500 | 采样点数（统计涨落 ±1.3%，远小于 0.2~0.6 空档） |

- overlap_frac < 0.2 → **界面贴合**（非缺陷）；0.2~0.6 → **部分重叠**（灰区，人工目检）；≥ 0.6 → **重叠型共位**（真 z-fighting 风险）。
- 误差方向：采样与候选截断只会漏判重合点、不会捏造 → 测出值是下界，"判为重叠的必然真重合"。实测分布双峰（界面类大件 <0.05、真重叠片 0.77~1.0），0.2~0.6 几乎是空的，阈值不敏感。

**实测三分**（`data/co_located_overlap_analysis.json`）：277 条 = 界面贴合 **175**（63%）/ 灰区 **52**（19%）/ 真重叠 **50**（18%）。真重叠集中在 p04（15）、p15（11）、p18（7）；7 个模型（p02/p03/p06/p08/p09/p19/p20）的共位 100% 是界面；>100 面大件 50 个里 46 个是界面。p15 的 50~132 面补丁成批出现（重叠率 0.3~0.93）是系统性重复几何信号。

- **修复**：分析层已完成（上）。**检出器组装层待用户拍板后落地**：`CoLocatedDetector` 加第二级分型（调 overlap 测量，`overlap_frac` 与 subtype 写进 finding 的 evidence/metrics）；interface 型 tier=keep（导出特性度量，不占复核队列）、overlap 型 review、灰区 review+目检标注；报告检出汇总与卡片结论句分列（预期 T2 数字：重叠 50 / 灰区 52 / 界面 175）。测量核心（`surface_samples`/`_SurfIndex`）已在 `meshq/core/detectors.py` 且有单测，组装仅剩"选最近邻→采样→占比→分型"一段。
- **预防**：①给检出结果贴缺陷标签前，必须验证"证据"与"几何实质"的对应——同一证据（焊接消失）可由多种几何产生，混合证据要按可测量的第二判据分型；②新增量化指标先定锚点几何（1/6、~1/2）再定阈值，锚点进单测；③把系统性普遍现象报成逐模型缺陷是误报叙事——测量驱动的区分（"识别并排除拆件的正常贴合"）才是正确交付姿态（用户明确立场）。
