# 沿法线微偏会把组件推到半透明灰底之后，颜色被冲淡

- **日期**：2026-09-23
- **现象**：定位图里组件颜色发白发灰（琥珀变成淡灰蓝），几乎辨认不出；同图的邻居颜色
  却是饱和的。两者只差偏移方向的处理。
- **根因**：为分离完全重合的表面，把组件/邻居沿**各自的顶点法线**微偏。偏移的符号取决于
  该件法线的朝向——重合薄片的法线朝内时，组件被推到灰底幽灵的表面**之后**，
  渲染时与 alpha 0.5 的幽灵混合而被冲淡。
- **修复**：改为一律朝**相机方向**（该方向的单位向量）平移：邻居偏 `offset`、
  组件偏 `2×offset`，两者必然都落在幽灵之前、且彼此不重合。
- **预防**：半透明对象与不透明对象同场时，"谁在前"直接决定颜色是否被冲淡；
  不要让对象自身的朝向决定偏移方向，**用相机方向这类已知外向量**保证层级关系。
- **关键词**：半透明, 深度序, 法线偏移, z-fighting, 冲淡, EEVEE
