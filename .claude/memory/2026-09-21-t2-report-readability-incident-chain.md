# T2 报告可读性修复轮的连环排查事故（2026-09-21）

- **日期**：2026-09-21
- **背景**：用户对 report_t2 提出五项可读性问题，修复轮中连环踩坑。根因、修复与教训按
  时间序记录。

## 1. Blender 对脚本内 Python 异常返回 0（被误报成功）

- **现象**：`render --force` 打印 `[ok]`，但产物 mtime 停留在上一轮——高亮通道崩溃后
  编排器毫无察觉。
- **根因**：Blender 对 `--python` 脚本内未捕获异常**默认返回退出码 0**；编排器只看
  returncode，于是把崩溃当成功。
- **修复**：`build_cmd` 加 `--python-exit-code 1`。
- **教训**：对 Blender 子进程，"退出码 0"不等于成功；**核对产物 mtime 才是真验收**。
  任何 headless 工具都要确认"异常→非零退出码"的默认行为。

## 2. "影子"假说被对照实验推翻：真凶是 Wireframe even_offset

- **现象**：线框三视图出现贯穿画面的横线/交叉线，初版分析判定为"线框笼子投在地面上的
  影子"（表面特征全部吻合：贴地、双方向交叉、随视角旋转）。
- **推翻过程**：按影子假说加 `visible_shadow=False` 重渲——**线条仍在**；再做 A/B：
  去掉 Wireframe 修改器重渲同机位——线条消失 → 定位到修改器本身。
- **真根因**：`use_even_offset=True` 按各面世界空间平面法线算厚度偏移，退化/自交面
  （T2 网格自交面 441~4705 个/模型）法线无意义 → 偏移爆炸，求值网格出现 49 条最长
  **7.2 倍对角线**的巨型薄壳边。`use_even_offset=False` 后归零（最长边 0.09）。
- **教训**：外观特征吻合 ≠ 根因。**对渲染产物做"去掉可疑组件"的 A/B 实验**比按特征
  推理快得多；第一次猜错不可怕，用实验裁决即可。另：修错误结论要回写分析文档留痕。

## 3. pieces 容器类型想当然

- **现象**：`render_highlight_channel` 内 `{pid for pid in pieces}` 报
  `unhashable type: 'dict'`。
- **根因**：`sort_pieces` 返回的是**列表**（元素为含 `pid` 键的字典），不是
  `{pid: piece}` 字典；迭代得到的是 dict 而非 pid。
- **教训**：跨模块改动前先确认集合类型；bpy 侧数据结构没有类型标注，靠读
  `bpy_geom.py` 源码而非猜。

## 4. embed() 统一 420px 降采样 → 凡是显示尺寸大于 420 的图必糊

- **现象**：逐组件放大拼图、对比图在网页上糊。
- **根因**：`report.embed()` 对所有图统一 `max_width=420`，而模板里
  review_sheet 显示宽 1100px、compare 显示 530px——**先压到 420 再放大显示**。
- **教训**：图片管线要"按显示尺寸决定嵌入分辨率"；新增大尺寸展示位时必须同步
  检查 embed 上限。（本轮修复：embed 增加 per-image max_width 参数。）

## 5. PIL 文件句柄让 Windows 测试 unlink 报 PermissionError

- **现象**：测试里 `Image.open(...)` 后再 `unlink()` 同一文件 → WinError 32。
- **修复**：用 `with Image.open(...)` 或先 `load()`。
- **教训**：Windows 上 PIL 惰性加载持句柄；测试断言图片尺寸一律用 with 块。

## 6. 三张 jsonl 表被 `--keys + --force` 整表覆写（连带发现备份盲区）

- **现象**：只想重算 2 个模型，`metrics/parts/part_verdicts.jsonl` 从 21 条变 2 条。
- **根因**：`metrics`/`part_features` 的 `--force` 分支**不读旧文件**，配合
  `--keys` 只重算部分键 → 未列出键随整表覆写丢失。备份目录只存 raw + tasks.json，
  救不了这三张表（可从 GLB 全量重跑恢复，未损失数据）。
- **修复**：只有不带 `--keys` 的全量 `--force` 才允许从零重建；带 `--keys` 时其余
  记录强制保留（回归单测钉住）。
- **教训**：**"强制重算"与"全量重建"是两种语义，不能共用一个开关**；部分重算的
  写盘必须是合并语义。jsonl 表不在备份范围内，重建路径（本地 GLB → 全链重跑）
  就是唯一兜底，所幸它确定性成立。
