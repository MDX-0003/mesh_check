# 视觉岛聚类：方法学依据与"采样高估"警告（岛层已产品化）

- **日期**：实验 2026-09-21（commit `44bbdbe`）；定稿并实施 2026-09-22（PLAN-04，`meshq/core/detectors.py` FloatingIslandDetector）
- **要点**：
  1. **朴素大半径量化焊接是破坏性的，不可用**：量化焊接移动顶点——薄壳正反面焊死、面退化丢弃（p06 83 块→1e-2 时 2144 块）。既掩盖问题又破坏网格。
  2. **正确算子 = 非破坏性近邻聚类（视觉岛）**：节点 = 细层组件（weld + 连通分量），边 = 组件间精确最小距离，ε 砍边后连通分量 = 岛。**单连接语义**（链路 ≤ε 即同岛）是人眼"视觉连续"的数学化；complete-linkage 会把一只鞋拆碎。
  3. **ε=3% 对角线固定**（config `parts.island_eps_ratio`）：全批 42 模型平台区验证。⚠ **原扫描的平台区结论部分是采样伪影**——500 点采样把 p06@standard 的 0 间隙高估成 3.05%+。引用旧扫描数字（`data/island_sweep.json`）前必须看 v2 精确距离复核结果（PLAN-04 §六"偏差与翻案"）。
  4. 少组件模型优雅退化：单组件模型任何 ε 下零浮岛是定义使然的正确结果，不产生噪声。
  5. 两批缺陷形态不同（standard=悬浮碎片，T2=表面异常/共位），岛层（空间检出）+ 细粒度级联（表面判别）合起来才是完整检出；legacy 碎片面率红线已退役（T2 多组件形态语义失真）。
- **产物**：岛明细 `data/islands.jsonl`（每模型 eps_ratio、岛列表、gap_ratio、floating 标记）；T2 精确距离下新见 p06（37 件@10.9%）/p11（84 件@4.85%）整组位移、p18 单件悬浮——组内贴合掩盖整组疏离，近邻级联不可见，这是岛层视角的价值实证。
- **遗留限制**：最小距离不度量接触面积/形态（点接触与面融合等价）——共位的面积维度由 overlap_frac 分型补上（见 bug 记录 2026-09-22-coloc-*）。
