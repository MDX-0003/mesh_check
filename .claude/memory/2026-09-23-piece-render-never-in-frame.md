# 单件图证从未把组件渲进画面（陈旧 bound_box + 绝对裁剪面）

- **日期**：2026-09-23
- **现象**：交付页"图证"列的条带里没有组件——把旧交付条带的第一张切出来看，只有渐变背景
  加一条水平的**地面边缘线**；用"与背景不同的像素"统计，组件像素为 **0**。该通道是
  仅单引擎可见的那 39% 检出**唯一的视觉证据**，等于一直是空的，而它此前从未被任何断言发现。
- **根因**：两点叠加。
  1. 贴合机位取 `display.bound_box`，而 `normalize(obj)` 走的是 `me.transform(mat)`
     （**就地改网格数据**），`bound_box` 要等 depsgraph 更新才跟上——刚 normalize 完就读它，
     拿到的是**变换前的旧框**，于是相机被放到旧位置（p01 实测 72.96/48.56/127.5），
     而组件早已被移到原点附近，**落在画外**。
  2. `clip_start` 用绝对值 0.1，而退化薄片归一化前可小到 1e-3；即便机位对了，
     组件也会被近裁剪面切掉。
- **修复**：机位包围盒改为**从顶点直接算**（`matrix_world @ v.co` 遍历 `display.data.vertices`），
  并让 `clip_start/clip_end` 随组件尺度走（`diag*0.01` / `diag*100`）。
- **预防**：
  1. 在 Blender 里读 `bound_box` / `dimensions` 前先确认自上次网格变换以来 depsgraph 已更新；
     **能从顶点算就别读缓存框**。
  2. 相机裁剪面在"对象尺度可能跨几个数量级"的场景里必须随尺度设，不能沿用固定值。
  3. 图片类产物的验收要断言**内容非空**（如组件像素占比下限），不能只看"文件生成 + 方差 > 0"——
     渐变背景加一条地面边缘线的方差足以通过旧判据。
- **关键词**：blender, bound_box, depsgraph, clip_start, 单件图证, 空图, 贴合机位
