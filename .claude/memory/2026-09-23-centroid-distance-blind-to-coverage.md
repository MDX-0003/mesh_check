# 面质心距离测不出"大面被小面盖住"（重叠分色在邻居侧失效）

- **日期**：2026-09-23
- **现象**：定位图的三色布尔拆分里，邻居侧**全判为"未重叠"**——p18 那条检出的 513 个面
  全部落进"邻居独有"色，表示重叠的品红一个都没出现；而组件侧判定正常。
- **根因**：判据是"该面**质心**到另一件表面的最近距离 ≤ tol"。它能测出"小面落在大面上"
  （小面质心必然贴近大面），但**测不出"大面被小面盖住"**：大面的质心离那块小面很远，
  即使大面有一片区域与小面完全重合。
- **修复**：重叠那一片改由**组件侧单独承担**（组件的面小、判据可靠），邻居整体一个颜色。
  语义仍成立：品红 = 该组件与邻居重合的部分；青 = 邻居。
- **预防**：凡涉及"面 vs 面覆盖"的判定，**单点采样（质心、顶点）都不够**——要么做面-面
  2D 布尔，要么把判据落在**较小的那一侧**。用采样判据时先问一句"被采样的面会不会比
  目标大得多"。
- **关键词**：几何判据, 质心距离, 覆盖, 布尔拆分, 采样盲区, 定位图
