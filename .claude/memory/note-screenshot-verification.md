# 截图验证约定：先断言 DOM，再看图

- **日期**：2026-09-23
- **事实**：用浏览器工具在**较宽视口**下截图时，出现过**重复列与陈旧帧**——
  同一张截图里右侧重复了一份内容，底部还出现了**已经被删掉**的章节标题
  （`定位 · 判别着色三视图`）。当时据此差点判定"模板改动没生效"，
  而实际上生成文件里该字符串出现 **0 次**（`grep -c` 复核）。
- **约定**：
  1. 判断"页面是否已更新"一律**先用 `evaluate` 断言关键文本/元素**（`innerText.includes(...)`、
     `querySelectorAll('h2')` 的文本列表），**再**截图；截图只用于看版式与观感，
     不作为"内容是什么"的证据；
  2. 截图与来源不一致时，先 `reload()` 并等待，再断言，最后重截；
  3. 视口越窄越不容易触发重复列；需要整页时宁可分段窄幅截，也不要一张超宽图。
- **关键词**：浏览器, 截图, DOM 断言, 陈旧帧, 重复列, 验证方法
