# 离线快照：生成式 3D 资产几何质检（T2 批 / 2026-09-22）

**这是可以直接看的交付快照，不需要安装任何东西。**

## 怎么读

1. 在文件管理器里双击 `index.html`（或拖进浏览器）；
2. **队列页**列出 20 个模型与落位结论；每个模型卡片给出它是什么（中文类别 + 生成时的英文 prompt）、
   待复核条数与问题构成；
3. 点模型名进入**明细页**：首屏是检测结论与「入库裁决」卡（离线时按钮只读，会提示在本机操作），
   下面是「问题组件」表 —— 四列：**组件编号 / 单件外观 / 定位图 / 问题**。
   - **单件外观**：把该组件单独拿出来渲的三视图，回答"它长什么样"；
   - **定位图**：左面板给出它在整机里的位置（灰底是其余组件，半透明；环圈出该件），
     右面板贴近看它与邻居的关系；琥珀 = 该件未重合的部分、品红 = 与邻居重合的那一片、青 = 邻居；
     极小件在整机面板里可能只有几个像素，此时以单件外观为准；
   - **问题**：一句白话结论；下面小字是判据与量化（阈值、比例、是否退化薄片）；
   - 折叠区还有线框三视图（可辨三角面密度）。

> 页面是**离线只读**的：所有图片都是相对路径，随目录一起拷贝即可正常显示；
> 在线裁决需要在本机运行仓库里的 `python -m meshq.tools.review_server <交付目录>`。

## 内容

| 路径 | 内容 |
|---|---|
| `index.html` | 交付队列（落位三类别 + 白话问题摘要 + 每模型干净渲染） |
| `passed/` · `pending/` · `failed/` | 各模型明细页与其图证、`model.glb`、几何检查记录（`blender_checks.json`） |
| `data/` | 检出与视觉岛记录、批次汇总、prompt 定义（页面上的数字都出自这里，可逐条核对） |
| `交付说明.md` | 交付说明书：prompt 选型 / 评估结论 / 检测选题与效果 / 两个引擎的分工 / 怎么跑起来 |

## 怎么复现

仓库根目录执行（需要 Meshy API 与 Blender，见仓库 README）：

```bash
python -m meshq.stages.deliver --date 2026-09-22 --out publish --snapshot
```

原始渲染中间件不在本快照内（占交付目录体积的绝大多数），可由 `data/` 重建。
